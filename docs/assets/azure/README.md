# Azure service icons

These four SVG files come from Microsoft's Azure Public Service Icons V24 package and are used unchanged to identify the corresponding Azure services in the project documentation.

| File | Microsoft source file |
| --- | --- |
| `virtual-network.svg` | `10061-icon-service-Virtual-Networks.svg` |
| `vm-scale-sets.svg` | `10034-icon-service-VM-Scale-Sets.svg` |
| `key-vault.svg` | `10245-icon-service-Key-Vaults.svg` |
| `azure-monitor.svg` | `00001-icon-service-Monitor.svg` |

Source and permitted-use terms: [Microsoft Azure Architecture Center](https://learn.microsoft.com/en-us/azure/architecture/icons/). Downloaded October 23, 2026. Microsoft retains ownership of the service icons.

`service-overview.jpg` arranges these icons at equal sizes with labels for consistent display in Markdown previews. The original SVG files remain unchanged.
