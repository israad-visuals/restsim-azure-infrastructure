# RestSim product previews

These images introduce the live business behind the Azure infrastructure project.

- `restsim-website.png`: the homepage screenshot supplied for this README on October 23, 2026, preserved unchanged. It is a product preview, not a source of verified traffic or download statistics.
- `restsim-app-home.png`: one existing RestSim app store image, reused without changes. It is a product preview rather than Azure runtime evidence.
- `app-store-badge.png` and `google-play-badge.png`: store badges already used on the RestSim website, linked to the verified public listings.
- `website-badge.svg`: a matching website link with a globe icon.
- `restsim-wordmark.png`, `restsim-lockup.png` and `restsim-mascot.png`: the current RestSim brand assets, reused unchanged. The mascot wears a green beanie and backpack.
- `restsim-azure-header.jpg`: a header composed from the brand assets with RestSim's navy, green and mint palette.
- `restsim-product-preview.jpg`: a compact layout of the website capture and existing app store artwork.
- `app-store-link.svg` and `google-play-link.svg`: the existing store badges displayed at a consistent 60-pixel height without changing their proportions.

The website and both app listings were checked on October 23, 2026. Preview images can differ from later releases; the linked website and listings show the current product.
